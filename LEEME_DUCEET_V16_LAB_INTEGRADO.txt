EJECUCIÓN
1. Extrae TODO el ZIP en una carpeta nueva.
2. Abre el archivo HTML integrado en Chrome o Edge.
3. Para fuentes que dependan del servidor local, ejecuta el servidor Node.js si tu instalación v16 lo utiliza.
4. Mantén la carpeta duceet-laboratorio junto al HTML: las plantillas Word se descargan desde ahí.
